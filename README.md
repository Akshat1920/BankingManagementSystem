# Banking Management System

A full-stack Banking Transaction Processing System built using Java, MySQL, and React.

## Features

- Customer and account management
- Deposit and withdrawal operations
- Account-to-account transfers
- Multithreaded transaction processing
- Concurrency control and transaction safety
- Transaction auditing and failure tracking
